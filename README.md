# 香港交通地圖

一幅可縮放的香港地圖。底圖用 [OpenFreeMap](https://openfreemap.org/) 的公開服務。圖上有港鐵十條重鐵，以及運輸署的交通快拍點。

點一個車站，會列出該站即將到站的班次。轉車站會按所屬路綫分開顯示。點一個快拍點，會顯示該處最新的路面照片。沒有班次、查詢太頻密，或照片載入失敗時，畫面上會寫明原因。

輕鐵不在港鐵這份到站資料內，所以這幅圖沒有輕鐵。

## 資料從哪裡來

- 底圖：OpenFreeMap 公開樣式。瀏覽器直接讀取，不經這個網站的伺服器。
- 車站名稱和行車順序：港鐵「路綫及車站」公開檔。馬場站不在該檔，但到站 API 有這站。賽馬日列車以馬場代替火炭，所以圖上另畫一條沙田經馬場到大學的路徑。
- 路綫曲線：OpenStreetMap 的路軌形狀，經 OpenFreeMap 地圖磚整理。畫的是路軌轉彎，不是車站之間的直線。
- 車站座標：瀏覽器直接向地政總署讀取車站範圍，再取中心點。網頁不會轉載這份座標。
- 到站班次：港鐵實時列車服務資訊。只在點選車站時查詢。
- 快拍點和照片：運輸署交通情況快拍圖像。

## 本機預覽

需要 Node.js 22.6 或以上。`npm run check` 使用這個版本才有的 TypeScript 直接執行。

```bash
npm install
npm run dev
```

開發伺服器會開在埠號 `4731`。

若要重新整理路綫和站名：

```bash
npm run network
```

`npm run check` 會即時核對車站是否全部對得上、快拍清單是否有 1013 點，以及中環是否有到站資料。

## 正式發佈

正式版打算放到 Cloudflare Workers 免費方案，使用平台提供的 `workers.dev` 網址，不另外買網域。靜態網頁的讀取次數不計入免費額度。地圖和政府資料由瀏覽器直接讀取。

這一版尚未發佈。驗收之後才部署：

```bash
npm run build
npx wrangler deploy
```

`wrangler.json` 已設成只發佈 `dist` 裡的靜態檔。預計費用是 0 美元。若每日需要 Worker 程式處理超過 10 萬次請求，或要改用自己的網域，才會產生費用。
